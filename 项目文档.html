📋 项目概览

YCDesk 是一款跨平台远程桌面控制应用，支持 Windows、Linux 和 Android 三大平台。项目采用 Electron + Capacitor + Node.js 技术栈，通过 WebRTC 实现低延迟远程桌面控制。

关键技术决策

  1. 双模块系统：shared/ 使用 ESM（import/export）；Electron 主进程使用 CJS（require）；平台副本使用 window. 全局模式。sync-shared.js 处理 Android ESM 适配。
  2. 无 TypeScript：当前全项目使用 Vanilla JavaScript。TypeScript 迁移属长期计划。
  3. 安全模型：AES-256-GCM + PBKDF2 凭据加密；timingSafeEqual 密码比较；5 次/30 秒速率限制。
  4. 状态管理：app-state.js 的简单可观察模式（get/set/on/off）。无 Redux/MobX。
  5. 构建系统：pkg (Windows 可执行文件)、Electron Builder（桌面应用）、Vite（Android）。

⚠️ 已知问题

🔴 linux/shared/ 未同步

sync-shared.js 未配置 Linux 同步目标。Phase 0-3 的安全修复（安全随机数、空 catch 日志等）未传播到 linux/shared/。同时 linux/shared/ 存在 7 个特有文件未纳入 canonical 源目录。

🟡 npm registry 不可用

registry.npmmirror.com 在此环境中返回 404，无法安装测试依赖和运行 npm test。所有需要 npm install 的操作均被跳过。

🟡 测试覆盖不足

~85K 行代码仅有 6 个测试套件（<5% 覆盖率）。核心模块（auth-manager、config、signaling-client）缺少单元测试。

🟡 大文件技术债

3 个文件超 1,000 行（input-handler.js 1,118行、app.js 1,453行、android/app.js 1,348行），拆分工作已延期。
