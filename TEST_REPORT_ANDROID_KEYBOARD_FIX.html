Android键盘→Windows被控端 输入修复验证报告

目标： 修复 Android 版主控端连接 Windows 被控端后，无法进行键盘输入的问题
修复版本： YCDesk-Portable-3.3.0.exe
构建位置： D:\MyProg\YCDesk\windows\dist-v2\YCDesk-Portable-3.3.0.exe

诊断发现的两个根本原因

问题1：C# 代码使用 struct 布局无法编译

诊断日志 input_sendinput.log 证实 PowerShell Add-Type 编译失败：

c:\Users\DHL\AppData\Local\Temp\latj0rih.0.cs(51) :  INPUT[] inputs = new INPUT[1];
c:\Users\DHL\AppData\Local\Temp\latj0rih.0.cs(52) :  inputs[0].type = INPUT_MOUSE;
c:\Users\DHL\AppData\Local\Temp\latj0rih.0.cs(53) :  inputs[0].u.mi.dx = x;
Add-Type : COMPILER_ERRORS

根因： C# 内联代码使用 INPUT[] struct 数组 + LayoutKind.Sequential，但缺少必要的 struct 定义和 using System.Windows.Forms。编译失败后 InputHelper 类不存在，所有键盘命令被 catch 块静默吞噬（输出 "OK" 伪装成功）。

问题2：PowerShell 不存在 [ushort] 类型加速器

Invoke-InputCommand 中调用 [InputHelper]::KeyDown([ushort][int]$Arg1)。[ushort] 是 C# 类型，PowerShell 只有 [uint16]。

修复内容

windows/src/main/input-sendinput.js C# 代码重构为 IntPtr 手动内存布局 用 Marshal.AllocHGlobal(INPUT_SIZE) + 偏移常量代替 struct 数组
移除对 INPUT 类型的依赖，直接操作指针
windows/src/main/input-sendinput.js [ushort] → [uint16] PowerShell Invoke-InputCommand 中 3 处键盘调用修正
